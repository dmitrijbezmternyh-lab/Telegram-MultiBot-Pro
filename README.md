Многофункциональный Telegram-бот с современной асинхронной архитектурой.

##  Возможности

-  **Погода** в любом городе (OpenWeatherMap)
-  **Курсы валют** и конвертер (ЦБ РФ)
- **Assistent** с контекстом диалога
-  **QR-код генератор**
-  **Мини-игры** и пасхалки
-  **Статистика** использования
-  **Админ-панель**
